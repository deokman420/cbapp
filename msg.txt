CB App v3.2.11 — catch up canonical (v3.2.9, v3.2.10, v3.2.11)

Canonical was two releases behind again at v3.2.8. This brings cbapp.html
and CHANGELOG.md level with the phbeks-site copy:

- v3.2.9  — canvas and windowed keep separate layouts
- v3.2.10 — a window belongs to the mode it was created in
- v3.2.11 — a backup is never plaintext

v3.2.11 is the substantive one. Backup used to mirror the session's own
state: Protect on gave you an encrypted .json, Protect off wrote every
note in the clear — backwards for the one artefact designed to leave the
machine. There is no plaintext path left. Protect on reuses that
passphrase; Protect off asks for a per-file one (twice, 6+ chars). Cancel
and no file is written. A per-file passphrase is sealed by
encryptForExport(), which bypasses the ensureSessionKey() cache so a
throwaway backup secret can never re-key this browser's own session.

README caught up too, including two claims that had been wrong since
v3.2.7: the HTML download no longer embeds your session, and Backup — not
"Download .html" — is how content leaves the browser.
